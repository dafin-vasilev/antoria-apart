КАК ДА ДОБАВИШ СНИМКИ

1. Качи JPG, JPEG, PNG или WEBP файлове в тази папка.
2. Не редактирай index.html.
3. Направи Commit changes.
4. GitHub Action автоматично ще обнови gallery.json.
5. Изчакай автоматизацията да завърши и сайтът ще покаже новите снимки.

Съвет: използвай кратки имена без интервали, например:

zaliv-obzor.jpg
sunset-2026.webp
